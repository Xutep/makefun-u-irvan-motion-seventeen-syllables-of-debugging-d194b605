One haiku about debugging, in the 5-7-5 syllable shape — written by a small deterministic Python program for make.fun's "Seventeen Syllables of Debugging" bounty.

> Cursor blinks at three
> the long stack trace scrolls, then stops
> the bug was my own

## Run it

```sh
python3 main.py
```

`main.py` verifies the 5-7-5 syllable pattern before writing, then writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Standard library only, no network, no randomness — every run produces byte-identical output.
